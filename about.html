I downloaded edict2.gz and did a manual search and replace to get rid of all those EntLnnnnnnnnX? things at the end of many of the entries in Visual Studio Code. Then saved that locally as with UTF-8 encoding and tested using the python light server described here.

Why did I do this?

I have been using the WWJDIC word search for some decades now along with Anki. Both have done well for me, but WWWJDIC keeps making round trips to the server which today's machines do not need to make. I wanted a quicker and easier process to build a custom vocabulary list while reading. Anki makes creating cards actually more difficult for me than creating paper cards. The only reason I don't go back to creating paper cards is the dust that those things collect. I don't like clutter. this is also a good Anki link for those more inclined toward electronic flashcards than paper.

But isn't the inconvenience of looking up a word in an old fashioned paper dictionary while reading from a paper book an important part of the learning process?

Yes, I believe it is. You definitely will benefit from sticking to that way. But it's not for all of us. Some of us do our reading on screens and like it that way. Reading is one of those things that does not work quite the same way for a lot of people. You have to do it the way that is comfortable for you or you will not do it. If you are thinking of learning Japanese, or any language that doesn't normally use the Roman alphabet, you have to quit being afraid of the Kanji. I am not sure you can ever beat paper and a pen for getting over that. I use this application to help decide what to write on paper next and I only keap the paper when it is helpful for seeing what my issues are. For a durable record, digital files are always going to be my first choice. This application might also be useful to those who swing the opposite way with respect to clutter and paper records.

Are there any other applications / coders that have contributed inspiration to this project

The main one is Kowloon. The author of that repo has demonstrated how to do an open-source project. I would have contributed some code to that if only I did not hate all of the frameworks involved. Since I do have such feelings, it's better to do my own thing my own with text and javascript.
